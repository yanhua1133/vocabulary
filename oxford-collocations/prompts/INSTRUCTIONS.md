# 搭配校对任务说明（给子 agent）

输入是 JSON 数组，元素形如：

```json
{"id": "can||aluminiumaluminumcan", "w": "can",
 "c": ["aluminium/aluminum can", "metal can", "tin can"],
 "cn": "铝罐;金属 罐;锡铁罐", "ex": ""}
```

- `w` 是词头，`c` 是这一格的搭配（已补成完整形式），`cn` 是从扫描件抽的中文解释，
  `ex` 是原书例句（英文 + 两个空格 + 中文，**可能为空、可能残缺**）。
- `cn` 和 `ex` 都是 OCR 出来的，**错字、串行、缺字很常见**。

对每一条输出 `{"<id>": {"cn": ..., "ex": ...}}`：

## `cn` —— 中文解释
- **只能是中文**，不许出现英文单词、`~`、`|`、`*` 这些残留。
- 修 OCR 错字：`放 斧⋯而转向⋯` → `放弃…而转向…`，`无声无息 也质止` → `无声无息地终止`。
- 去掉串进来的别的条目内容（`听任某人由命运摆布」 be left ~ed 被遗弃` 只留前半）。
- 不超过 20 字，多个义项用 `；` 分隔。
- 原来是空的，就按 `c` 里的搭配自己写一个。

## `ex` —— 例句
- 格式：**英文句子 + 两个空格 + 中文翻译**。两个空格是分隔符，
  句子内部不要出现连续两个空格。
- 英文 8-18 词，**必须完整**（有主谓、句末有标点），而且**必须用上 `c` 里的搭配**
  （可以按语法做时态/单复数变形）。
- 原书那句能用就修好了用（补全被 OCR 吃掉的词、改错字）；
  残缺得没法救、或者本来就是空的，**自己写一句**。
- 中文翻译要地道，不要逐字硬翻。
- **一条都不能留空**——输入里 `ex` 为空的那些，正是要你补的。
- 不要自己加 `<b>` 标签，渲染时会自动加粗。

## 如果 `c` 里的搭配本身就不对
OCR 会把相邻词条的内容混进来（`pure please` 其实是 `pure pleasure`）。
遇到这种，`cn` 和 `ex` 都按**正确的词**写，并在 `cn` 末尾加 `（搭配疑误）`，
方便回头筛出来。

## 输出要求
- 每个输入文件 `bNNN.json` 写一个 `bNNN.out.json` 在同一目录。
- 只输出裸 JSON，不要代码围栏、不要解释。
- key 用输入里的 `id` 原样照抄，一条都不能漏。
