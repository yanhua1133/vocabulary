## PDF 版式（与 Markdown 版的差异）
4 列：**单词**（第一行单词+音标，第二行词性+解释）/ **常用·口语** / **常用短语** / **例句**。
- 短语和例句**默认英文一行、中文一行**；只有分行怎么缩都放不下时，才退化成中英连排。
- **每格严格两行，绝不出现第三行**（全 31 册实测 0 个超行格）。行数不能估算，必须在浏览器里用
  Range 行盒实测（`td.scrollHeight` 是整行高度、由最高的格子决定，用它判断会全错），
  超两行就按比例缩字号，下限 4.2pt，从不裁字。生成时会打印「实测仍超过两行的格子」，必须是 0。
  - **量行数的页面必须 `viewport=609px` + `emulate_media("print")`**，否则量的是 1280px 屏幕布局，
    跟打印结果两样，会假报 0。
  - 缩到下限还超时分三级降级：短语/例句中英连排 → 第一列丢音标 → 第一列单词行与解释行连排。
- 解释超宽时先精简内容再缩字号：词性去点 `adj/n`、删互为子串的冗余释义、去括号补充说明。
- 短语列用词典缩写：someone→sb.、something→sth.
- 第一列不打删除线；常用度只有半颗星（`☆`）的近/反义词行整行略去。
- **渲染器用 playwright 自带 Chromium**：系统 Chrome 被企业策略（`enrollment-domain=gitlab.com`）
  禁掉了 headless 打印，`--print-to-pdf` 会静默什么都不写，导致拿旧文件当成功。
  `print_pdfs` 生成后校验文件确实被改写，否则直接报错。

## Markdown 版格式
7 列：单词 / 音标 / 常用 / 口语 / 词性 / 中文释义 / 常用短语。
例句不占列，紧跟在该词下面、跨整行显示（内嵌 HTML 表格 + `colspan`）。
- 词头加粗；近义词 `↳近`、反义词 `↳反`
- 星级：`★`=一颗，`☆`=半颗；不补尾部空星；最低分为半颗星 `☆`
- 单词列被 `~~~~` 包住 = 极其罕见（wordfreq Zipf < 1.5）
- 词性用中文全称（形容词、及物动词…）
- 常用短语格内两行：英文搭配 + 中文
- 例句 = 英文完整句 + 中文翻译，一律自写，不用原书例句
- 每个词的「词条行 + 例句行」装在同一个 `<tbody>`，PDF 打印时整组不跨页
- **PDF 版**额外略去常用度只有半颗星（`☆`）的近义词/反义词行（词头一律保留）；
  Markdown 版保留全部，两者内容差异仅此一项
