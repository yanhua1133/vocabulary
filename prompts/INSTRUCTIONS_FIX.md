# 修错批次规则

给你若干 `work/batches/FIX_NNN.json`。每个是 JSON 数组，元素形如：

```json
{"word": "defy", "problems": ["ex_missing"], "fix": ["example"],
 "ipa": "dɪˈfaɪ", "cn": "蔑视，公然反抗", "pos": "vt.",
 "phrase": "defy the court", "phrase_cn": "蔑视法庭", "example": "", "related_to": ""}
```

对**每个**文件：`Read` 它，然后 `Write` 同名 `.out.json`。
输出是**一个 JSON 对象**：键 = 输入 `word` 原样字符串，值 = 只含该词 `fix` 里列出的字段（修正后的值）。

## 问题码含义

| 码 | 含义 | 要做的事 |
|---|---|---|
| `ex_missing` | 缺例句 | 写一句新例句 |
| `ex_frag` / `ex_word` / `ex_glue` / `ex_len` | 例句被截断／不含该词／单词粘连／是短语不是句子 | 整句重写 |
| `cn_missing` / `cn_latin` | 缺中文释义／释义里混进英文 | 重写纯中文释义 |
| `ipa_bad` / `ipa_missing` | 音标错或缺 | 重写音标 |
| `ph_word` | 常用短语里没有该词 | 重写短语（和它的中文） |
| `pos_missing` / `pos_morph` | 词性缺失或与词形矛盾 | 给正确词性 |
| `spell` | 该词本身像是原书粘连产物 | 照常给字段即可 |

## 字段规则

- **example**：一个完整英文句子，**首字母大写、句末有标点**，8-20 词，必须自然包含该词
  或其屈折形式，单词之间正常空格；然后**两个空格**，再接中文翻译。
  不要用短语代替句子，不要带作者出处。
- **cn**：简体中文释义，≤20 字，多义用「；」分隔，**不许出现英文单词**。
  `related_to` 非空表示该词是那个词的近义词/反义词，取与该语境相关的义项。
- **ipa**：美式音标，不带斜线方括号，只用
  `ˈ ˌ ː a ɑ ɒ æ ʌ e ɛ ɜ ə ɪ i ɔ o ʊ u b d f ɡ h j k l m n p r s t v w z ʃ ʒ θ ð ŋ` 和空格；
  必须用 `ɡ`(U+0261)。多词条目词间用一个空格。
- **phrase**：含该词的常用英文搭配，2-5 词。改了 phrase 就同时给 `phrase_cn`（≤12 字中文）。
- **pos**：只用 `n. v. vt. vi. adj. adv. prep. conj. pron. num.`，多个用 `/` 连接。

## 硬要求

- 不许漏词；不许留空；只输出裸 JSON，不要代码围栏和解释文字。
- 只输出 `fix` 列出的字段，不要顺手改别的字段。
- 写完自查：键数 = 输入长度，每条的字段集 = 其 `fix`，例句都有句末标点和两个空格分隔的中文。
