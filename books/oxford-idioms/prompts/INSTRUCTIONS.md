# 批次任务说明（给子 agent）

你要处理若干个批次文件，每个文件是一个 JSON 数组，元素形如：

```json
{"id": 123, "w": "luck", "i": "sood ˈluck (with sth) (spoken)", "cn": "祝成功祝好运"}
```

- `w` 是关键词，`i` 是《牛津习语词典》里的习语条目（**OCR 出来的，可能有错字**），
  `cn` 是从原书扫描件里抽的中文释义（**可能为空、可能缺标点、可能有错**）。

对每一条，写出同名的 `*.out.json`，内容是 `{"<id>": {"i": ..., "cn": ..., "e": ...}}`：

- **`i`**：修正后的习语条目。
  - 只改明显的 OCR 错字：`sood ˈluck` → `good ˈluck`、`(informaf)` → `(informal)`、
    `(nformal)` → `(informal)`、`toˈB` → `to ˈB`。
  - **保留重音符号 ˈ 和 ˌ、保留 (informal)/(saying)/(BrE)/(AmE) 这类标签、
    保留 sb/sth/sb's 的写法、保留 `A ◆ B` 这种变体分隔**。
  - 拿不准就原样抄回来，不要自由发挥改写习语。
- **`cn`**：简体中文释义，不超过 25 字。
  - 输入的 `cn` 通常是对的，只是丢了标点（`祝成功祝好运` → `祝好运；祝成功`），
    把它整理通顺即可；为空或明显不对时自己写。
  - 多个义项用 `；` 分隔，不要写英文。
- **`e`**：一个例句，格式是 **英文句子 + 两个空格 + 中文翻译**。
  - 英文 8-18 词，必须**完整包含这个习语**（可以按语法做时态/人称变形）。
  - 自然、口语化、场景具体，不要教科书腔。
  - 中文翻译要地道，不要逐字硬翻。

## 输出要求

- 每个输入文件 `bNNN.json` 对应一个 `bNNN.out.json`，写在同一个目录下。
- 只输出裸 JSON，不要代码围栏、不要解释文字。
- **一条都不能漏**，输入多少个 id 就输出多少个 key。
- 全部用简体中文写释义和翻译。
